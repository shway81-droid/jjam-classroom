## 지켜야 할 규칙 (오늘 정한 것)

1. **사진은 그 사람 본인의 공용 분류에 들어 있어야 한다** (`own_cat2.py`).
   - 사진의 분류 가운데 후보 표(`cand_*.tsv` 세 번째 칸)의 분류 이름과 **철자까지 같은** 것이 있어야 한다
     ('Lee Su-ji' ≠ 'Lee Suji' — 하이픈 하나 차이로 다른 사람이 통과한 적이 있다).
   - 후보 분류에 `(comedian)` 같은 구분 말이 있으면, 사진 쪽 분류도 같은 계열 구분 말이어야 한다
     (개그맨 박준형을 찾다가 g.o.d 박준형이 통과한 적이 있다).
   - 그 본인 분류의 상위 분류가 연예인 계열(코미디언·방송인·배우·가수·셰프·유튜버…)이어야 하고,
     정치인·목사·외교관·장관 등이 섞이면 버린다.
2. **이름 검색 결과만으로는 쓰지 않는다** — 오늘 국회의원 정태호, 목사 오상진, 외교관 김숙, 장관 김현숙 사진이 이름 검색으로 섞였다.
3. 사진을 눈으로 한 장씩 본다: 여러 명이 나온 사진, 얼굴이 작거나 잘린 사진, 선글라스, 성별·시대가 명백히 안 맞는 사진은 뺀다.
4. **폰트에 없는 글자를 쓰지 않는다** (`cover.py hints.tsv`). 폰트를 바꾸면 공통 파일이라 일곱 사이트가 한꺼번에 다시 발행된다.
   그래서 로완 앳킨슨(앳)·오드리 헵번(헵)·양띵(띵)은 뺐고, 힌트의 꼰·숏·랩·굿·쎈·갤·켄 도 피해 다시 썼다.
5. 정치인·논란 있는 인물·미성년 때 사진은 넣지 않는다 (word/CLAUDE.md). 조세호·박나래·이수근 등은 처음부터 후보에서 뺐다.

## 위키미디어 접속 제한 (중요)

- 원본 파일·비표준 크기 직접 요청은 막힌다(429, retry-after 600초 벌칙). **표준 크기 썸네일(500·960·1280·1920px)만** 받는다 — `phase_b.thumb_url`. 근거: https://w.wiki/GHai
- API 는 5초 간격으로도 자주 429(30초 대기)가 난다. 한 명에 20~30초. 남은 102명 1단계에 50분쯤 걸린다.
- 같은 호스트에 프로세스 두 개를 동시에 돌리면 서로 한도를 깎아 먹는다.
- User-Agent 에는 저장소 주소만 넣는다(개인 메일 주소 금지).

## 파일

| 파일 | 내용 |
|---|---|
| `cand_*.tsv` | 후보: 분야 · 이름 · 공용 분류(\|로 여러 개) · 검색어 |
| `hints.tsv` | 분야 · 정답 · 난이도 · 힌트 설명(초성 뒤) · 이것도 정답(/) |
| `pick.json` | 검토 결과. `{"idx": n}` 또는 `{"idx": n, "box": [l,t,r,b]}`(0~1 비율) 또는 `"skip"` |
| `out/<분야_이름>/info.json` | 1단계: 라이선스·크기를 통과한 후보 파일 정보 |
| `out/<분야_이름>/allowed.json` | 본인 분류 규칙을 통과한 파일과 근거 분류 |
| `out/<분야_이름>/meta.json` | 2단계: 내려받은 후보, 얼굴 위치, 점수, 썸네일 주소(`dl`) |
| `cats_cache.json` | 파일·분류의 상위 분류 조회 결과(다시 묻지 않게) |
