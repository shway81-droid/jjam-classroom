## 1. 제품 개요

### 1.1 한 문장 정의
수업 자투리 시간에 전자칠판이 옛이야기 그림책 한 권을 넘기며 읽어 주고, 마지막에 질문 하나로 반 전체의 생각을 여는 '교실 속 읽어 주는 도서관'입니다.

### 1.2 해결하려는 문제
- 남는 3~5분에 책을 읽어 주고 싶어도, 그 자리에서 책을 고르고 큰 화면에 보여 줄 자료가 없습니다(실물 그림책은 뒷자리에서 안 보입니다).
- 유튜브 동화 영상은 광고·추천 영상·출처 불명 콘텐츠가 따라옵니다.
- 교사가 직접 읽으면 목이 쉬고, 매번 같은 책이 됩니다.

### 1.3 목표
1. **10초 안에 첫 장면**: 접속 → 책 고르기(3번 이하 클릭) → 첫 장면 낭독 시작.
2. **시작 후 조작 0회**: 낭독이 끝나면 다음 장면으로 저절로 넘어갑니다. 교사는 멈추기·되돌리기만 필요할 때 씁니다.
3. **뒷자리에서도 보이고 들리게**: 글은 본문 최소 40px 상당, 낭독은 교실 스피커 기준 음량 정규화.
4. **저작권 위험 0**: 원전은 저작권 만료, 글은 직접 다시 씀(재화), 그림·음성은 자체 생성.
5. **개인정보 0**: 학생 이름·답변을 받지 않습니다.

### 1.4 비목표 (이번에 하지 않음)
- 학생이 만든 그림책 올리기('한 아이 한 권'): 학생 저작물·초상·개인정보 문제를 따로 설계해야 합니다. 다음 단계로 미룹니다.
- 학생 개인 독서 기록, 로그인, 서버 저장.
- 현대 그림책(저작권이 살아 있는 책) 수록 또는 그 문장·그림 참고.
- 장면마다 퀴즈·토론 단계(이야기 사이트의 영역).
- 등장인물별 다른 목소리(MVP는 화자 한 명. 2단계 후보).

## 2. 사용자와 환경

### 주요 사용자
- 1~6학년 담임교사. 특히 저학년(1~3학년)은 '읽어 주기', 고학년은 '그림만 보고 이야기 짓기' 모드를 기대합니다.

### 사용 환경
- 전자칠판 1920×1080 또는 1280×720, 교실 스피커, 크롬·웨일·삼성 인터넷.
- 학교 와이파이가 불안정할 수 있습니다 → 한 번 연 책은 오프라인 재생(6장).
- 프레젠터 리모컨(PageUp/PageDown)으로 교실 뒤에서 넘길 수 있어야 합니다(그리기 3.3 선례).

## 3. 콘텐츠 체계

### 3.1 원전과 재화 원칙
| 원전 | 저작권 근거 | 주의 |
|---|---|---|
| 한국 옛이야기(구전) | 저작자 없는 구전 설화 | **현대 그림책·전집의 문장과 그림을 참고하지 않습니다.** 줄거리 뼈대만 쓰고 문장은 새로 씁니다 |
| 이솝 우화 | 고대 그리스 | 번역본 문장을 옮기지 않습니다. 새로 씁니다 |
| 그림 형제(1859·1863 사망), 안데르센(1875 사망) | 사후 70년 경과 | 원전 줄거리만, 현대 번역·디즈니 등 각색 요소(이름·장면)를 쓰지 않습니다 |

- 권마다 `origin.basis`(원전 이름과 근거)와 `retold: "자체 재화"`를 적고, 검증 스크립트가 비어 있으면 실패시킵니다.
- 그림·음성이 AI 생성임을 시작 화면과 정보 창에 밝힙니다(1분사회 선례). 음성은 엔진 이름과 OmniVoice 저작자(CC-BY-NC 표시 조건)를 함께 적습니다.

### 3.2 한 권의 짜임
- **8~12장면**, 장면마다 그림 1장 + 글 1~3문장(장면당 낭독 15~30초).
- 길이: **3분 권**(8장면 안팎)과 **5분 권**(12장면 안팎). 목록에서 시간으로 고릅니다.
- 마지막 장면 다음에 **질문 하나**("나라면 어떻게 했을까?"류). 정답이 없음을 화면에 적습니다.
- 첫 장 앞에 표지(제목·원전·짧은 한 줄 소개).

### 3.3 MVP 후보 (구현 세션에서 30권 확정)
- **한국 옛이야기:** 금도끼 은도끼, 혹부리 영감, 의좋은 형제, 은혜 갚은 까치, 팥죽 할멈과 호랑이, 소금을 만드는 맷돌(바닷물이 짠 이유), 토끼의 간, 견우와 직녀, 개와 고양이와 구슬, 방귀쟁이 며느리, 좁쌀 한 톨, 해와 달이 된 오누이(수위 조정 필수), 흥부와 놀부, 도깨비 방망이, 청개구리
- **이솝 우화:** 토끼와 거북, 개미와 베짱이, 양치기 소년, 여우와 신 포도, 북풍과 해님, 사자와 생쥐, 시골 쥐와 도시 쥐, 황금 알을 낳는 거위, 까마귀와 물병, 여우와 두루미
- **그림 형제·안데르센:** 브레멘 음악대, 요정과 구두장이, 미운 오리 새끼, 벌거벗은 임금님, 달콤한 죽 냄비

### 3.4 안전 기준 (짬짬이 이야기 기준을 따름)
- `sensitivity: "low"` 만 목록에 나옵니다.
- 옛이야기의 잔혹한 장면(잡아먹힘, 처벌, 죽음)은 **장면으로 보여 주지 않고 문장으로도 직접 묘사하지 않습니다.** 줄거리상 꼭 필요하면 완화한 표현으로 바꾸고 `cautions` 에 무엇을 바꿨는지 적습니다.
- 고정관념 점검: 계모 악역, 외모 조롱(혹부리·미운 오리), 성별 역할을 재화할 때 조롱으로 읽히지 않게 씁니다. 점검 결과를 `cautions` 에 남깁니다.
- 그림: 무서운 표정·피·무기 클로즈업 금지. 아이 등장인물은 실존 인물처럼 보이지 않게 그림체로 그립니다.

### 3.5 글 쓰기 기준
- 1~2학년도 듣고 이해하는 낱말, 한 문장 25자 안팎, 의성어·의태어를 살립니다(소리 내어 읽기 좋게).
- 반복 구조(옛이야기의 세 번 되풀이)를 살려 학생이 따라 말할 수 있게 합니다.
- 공용 웹폰트 서브셋(`assets/fonts/coverage.txt`)에 없는 글자를 쓰지 않습니다(`check-font-coverage.mjs`). 리듬에서 '챌'이 빠져 이름을 바꾼 선례가 있습니다.

## 4. 핵심 흐름

```
서가(책 목록) ── 고르기: 시간(3분/5분) · 원전(옛이야기/우화/명작) · 🎲 오늘의 그림책
   │
표지 ── [읽어 주기 시작] (소리 켬과 같은 탭)
   │
장면 1 … 장면 N ── 낭독 끝나면 1.5초 쉬고 자동으로 다음 장 (넘김 효과는 가볍게)
   │
마지막 질문 ── "정답이 없어요" 표시, 생각 시간 타이머(30·60초, 선택)
   │
다 읽었어요 ── 서가 도장(우리 반이 읽은 권수 +1), 다른 책 고르기
```

### 4.1 읽기 모드 (표지에서 고름, 기본 '읽어 주기')
| 모드 | 소리 | 넘김 | 쓰임 |
|---|---|---|---|
| 읽어 주기 | 낭독 음성 | 자동 | 기본. 교사 조작 0회 |
| 선생님이 읽기 | 끔 | 교사가 넘김 | 교사가 직접 실감 나게 읽고 싶을 때. 글은 크게 |
| 그림만 보고 이야기 짓기 | 끔, 글 숨김 | 교사가 넘김 | 고학년. 그림을 보고 반이 이야기를 지어 말한 뒤 마지막에 '원래 이야기' 낭독 |

## 5. 화면

- **서가:** 책등이 꽂힌 책장 느낌의 표지 카드 그리드(표지 그림 + 제목 + 시간 배지). 다 읽은 책에는 작은 도장. 위쪽에 필터 3개와 '오늘의 그림책'.
- **읽기 화면:** 가로 16:9. 그림이 화면 가득, 글은 아래쪽 반투명 띠에 겹침(D3). 띠 높이는 글 줄 수만큼만. 지금 읽는 문장을 굵게(문장 구간 `voice.json` 기준). 오른쪽 아래 작은 진행 점(장면 수).
- **조작(키, 그리기와 맞춤):** `Space`/`→`/`PageDown` 다음 장, `←`/`PageUp` 앞 장(자동 넘김 멈춤), `P` 자동 넘김 멈춤·재개, `S` 이 장 다시 듣기, `T` 글 띠 숨기기·보이기, `F` 전체화면, `Esc` 나가기(화면 안 확인). 글자 키는 `e.code` 로 읽습니다.
- **디자인:** 가족 공통 헤더(색 띠 + 로고 + 제목 + 부제). 읽기 화면은 헤더를 숨기고 그림에 집중합니다.

## 6. 기능 요구사항

| # | 기능 | 기준 |
|---|---|---|
| F1 | 서가 필터·오늘의 그림책 | 날짜 시드로 반 전체가 같은 '오늘의 그림책'. 최근 읽은 5권은 오늘의 그림책에서 뺌 |
| F2 | 자동 낭독·넘김 | 타이머는 시각 차이 기준(`setTimeout` 누적 금지, 그리기 3.2) |
| F3 | 문장 강조 | 낭독 중인 문장을 굵게. 음성 파일 하나 = 책 하나 = 목소리 하나, 문장 구간은 `voice.json` |
| F4 | 목소리·소리 설정 | 여자/남자, 읽어 주기/끔. localStorage 에 기억 |
| F5 | 마지막 질문 | 질문 1개 + 선택 타이머. 학생 답 입력 없음 |
| F6 | 우리 반 서가 도장 | 이 기기 localStorage 에 '읽은 책 id 목록'만. 이름·날짜별 기록 없음. '도장 지우기' 버튼 |
| F7 | 오프라인 | 서가·글·표지는 첫 방문에 캐시. 그림·음성은 **연 책만** 캐시(30권 전체는 무거움). 표지에 '이 책 미리 받기' |
| F8 | 이미지 로딩 | 다음 장 그림을 미리 불러 넘김이 끊기지 않게 |
| F9 | 정보 창 | 원전·재화·AI 생성 표시·출처(ATTRIBUTION) |

## 7. 데이터 구조

`books/<id>/book.json` 하나가 원본이고, `data/books.json`(목록 통합본, 1요청)과 `data/voice.json` 은 파생물입니다(그리기 방식).

```json
{
  "id": "golden-axe",
  "title": "금도끼 은도끼",
  "origin": { "type": "korean-folk", "basis": "한국 구전 설화(저작자 없음)" },
  "retold": "자체 재화",
  "grades": [1, 2, 3, 4],
  "minutes": 3,
  "sensitivity": "low",
  "cautions": "",
  "blurb": "정직한 나무꾼과 산신령 이야기",
  "pages": [
    { "image": "p01.webp", "text": ["옛날 옛날 깊은 산골에 나무꾼이 살았어요.", "나무꾼은 날마다 쓱싹쓱싹 나무를 했지요."] }
  ],
  "question": "내가 나무꾼이었다면 산신령에게 뭐라고 말했을까요?",
  "keywords": ["정직", "욕심"],
  "art": { "style": "<D5에서 정한 화풍 이름>", "characterSheet": "char.webp" }
}
```

- 그림: `books/<id>/pNN.webp`, 1600×900, 권당 합계 2MB 이하 목표. 표지 `cover.webp`.
- 음성: `audio/<목소리>/<id>-<멘트해시>.mp3` (그리기와 같은 이름 규칙, 글을 고친 책만 다시 만듦).
- `origin.type`: `korean-folk` · `aesop` · `grimm` · `andersen`.

## 8. 제작 파이프라인 (이 프로젝트 고유의 준비 작업)

1. **글:** 원전 줄거리 확인 → 재화 원고 작성(3.4·3.5 기준) → 사용자 검토. 원고는 `book.json` 의 `pages[].text`.
2. **캐릭터 시트:** 권마다 주인공·주요 인물의 모습을 한 장으로 먼저 생성(`char.webp`, 배포 제외 가능). 장면 그림이 같은 인물로 보이게 하는 기준입니다.
3. **장면 그림:** codex-image 로 장면당 1장(5장 동시 병렬). 프롬프트 = 고정 화풍 문구 + 캐릭터 시트 묘사 + 장면 설명. 장면과 글이 맞는지, 안전 기준(3.4)을 사람이 확인합니다.
4. **음성:** `scripts/voice/build.py` 로 책 단위 생성(목소리·엔진은 `engine.py`, VoiceStudio 를 켜 둠) → `verify.py`(Whisper)로 원문과 다르게 읽은 문장 찾기 → `retake.py` 로 그 문장만 다시 → 음량 정규화.
5. **검증:** `npm test` 가 스키마·id 중복·`origin.basis` 누락·그림/음성 파일 존재·장면 수(8~12)·문장 길이·폰트 커버리지를 확인합니다.

## 9. 기술 구성
- HTML · CSS · Vanilla JavaScript, 빌드 단계 없음(가족 공통)
- `data/books.json` + `books/<id>/` + `audio/` + localStorage, 서버·DB 없음
- 서비스 워커(목록·글은 캐시 우선, 그림·음성은 연 책만 저장)
- 넘김 효과는 CSS 페이드 정도로 가볍게(싼 전자칠판에서 끊기지 않게)

## 10. MVP 필수 범위
- 30권(D2 구성), 권당 8~12장면, 그림·낭독(목소리 2) 완비
- 서가·필터·오늘의 그림책·도장
- 읽기 모드 3가지, 키·리모컨 조작
- 마지막 질문 + 선택 타이머
- 연 책 오프라인 재생, 다음 장 미리 불러오기
- 검증 스크립트 + CI

## 11. 완료 기준
- 접속부터 첫 장면 낭독까지 10초 이내(캐시된 상태 기준)
- '읽어 주기'로 한 권을 끝까지 교사 조작 0회로 읽음
- 전 권 `origin.basis`·`retold` 기록, ATTRIBUTION 과 권수 일치
- Whisper 검증에서 원문과 다르게 읽은 문장 0개
- 전자칠판 실환경에서 뒷자리 학생이 글을 읽을 수 있고 낭독이 들림
- 한 번 읽은 책을 인터넷을 끊고 다시 읽을 수 있음
- 안전 기준 점검표(3.4)를 30권 모두 통과

## 12. 개발 순서
1. D1~D6 확인, 폴더와 기본 파일(`index.html`·`favicon.svg`·`sw.js`·`package.json`) 만들기
2. **한 권 세로 관통:** '금도끼 은도끼' 원고 → 화풍 시안 3개(D5) → 사용자 선택 → 캐릭터 시트·장면 그림 → 음성 → 읽기 화면에서 끝까지 재생
3. 서가·필터·오늘의 그림책·도장
4. 읽기 모드 3가지·키 조작·마지막 질문
5. `validate-data`·폰트 커버리지·CI(경로 필터)
6. 나머지 29권 제작(원고 묶음 → 사용자 검토 → 그림 → 음성 → 검증). 원고는 5권씩 묶어 검토받습니다
7. 서비스 워커(연 책 캐시)·미리 받기·오프라인 점검
8. 아이콘 색 렌더링 비교 → 확정
9. 교실 전자칠판 실측(글 크기·음량) → 사용자에게 발행·연결(D6) 여부를 묻습니다

## 13. 제품 원칙
