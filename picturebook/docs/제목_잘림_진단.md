# 여자 목소리 제목 끝 잘림 — 진단과 고치는 순서 (2026-11-24)

**제보**: 도깨비 방망이 · 토끼와 거북 · 브레멘 음악대를 여자 목소리(`vox-f`)로 들으면, 제목을 끝까지 읽지 않고 끝이 잘립니다.

**판정**: **음성 파일 자체가 잘렸습니다.** 재생 코드는 원인이 아닙니다.
다른 컴퓨터(집 맥)에서 세 권의 `vox-f` 제목만 다시 만들어 끼우면 됩니다. 아래 '고치는 순서'를 보세요.

## 2026-11-25 덧붙임 — 진짜 원인과 고친 방법 (집 맥)
- **VoxCPM2 가 짧은 글을 끝 음절 도중에 멈춥니다.** 엔진이 낸 원래 wav 를 보면 말소리(-9~-15dB)가 파일 맨 끝까지 이어지다 끊깁니다.
  길이도 1.44·1.60·1.76·1.92초처럼 0.16초 덩어리의 배수입니다. 아래 3번의 "추측"이 맞았습니다.
- seed 를 바꿔도, 마침표를 붙여도, VoiceStudio 의 `duration`·`denoise`·`postprocess_output` 을 바꿔도 같았습니다.
  그래서 여러 번 만들어 고르는 것(첫 시도, 후보 64개)으로는 "덜 잘린 것"만 고를 뿐이었고, 선생님이 들으니 여전히 잘렸습니다.
- **고친 방법**: 제목을 `제목. 제목.` 으로 두 번 읽혀 쉬는 자리에서 잘라 첫 번째만 씁니다(`build.py` 의 `say_title`,
  `engine.py` 의 `title_twice` — 여자 목소리만). 첫 번째는 쉼 앞에서 스스로 끝나 끝이 자연스럽게 작아집니다.
  앞으로 만드는 책의 제목도 이 방법으로 만들어집니다.
- **받아쓰기 함정**: '브레멘 음악대'는 표준 발음대로 이어 읽으면 [브레메느막때]라, 받아쓰기가 '프레멘은 맞대'·'프레멘 음악데'로 적습니다.
  그래서 브레멘은 받아쓰기로 고를 수 없어 후보를 사람이 들어 고르게 했습니다(`retake.py --redo --only N`).

## 증거

### 1. 제목 구간 길이 (`data/voice.json` 의 `title`, 초)
| 책 | vox-f | omni-m | 제보 |
|---|---|---|---|
| 브레멘 음악대 `bremen-musicians` | **0.70** | 1.52 | 잘림 |
| 토끼와 거북 `tortoise-hare` | **0.81** | 1.44 | 잘림 |
| 도깨비 방망이 `goblin-club` | 0.98 | 1.20 | 잘림 |
| 금도끼 은도끼 `golden-axe` | 1.24 | 1.56 | 정상 |
| 의좋은 형제 `good-brothers` | 0.93 | 1.00 | 정상 |
| 북풍과 해님 `wind-and-sun` | 0.93 | 1.34 | 정상 |

### 2. 받아쓰기 (Whisper small, 제목 구간만 잘라서)
- 브레멘 vox-f: '브래멘 음악' — **'대'가 없습니다.**
- 토끼와 거북 vox-f: '토끼와 거부' — **'북'의 받침 ㄱ이 없습니다.**
- 도깨비 vox-f: '도깨비 방망이' — 글자는 다 들리지만 아래 3번처럼 마지막 음절이 중간에 끊깁니다.
- 남자 목소리 여섯 권과 여자 목소리 나머지 세 권은 끝까지 들립니다.

### 3. 끝소리 크기 (10ms 단위, dB)
- 도깨비 vox-f: … -20, -19, **-38, -55, -67** — 10ms 만에 말소리에서 무음으로 떨어집니다.
- 브레멘 vox-f: … -21, -26, **-42, -49**
- 토끼와 거북 vox-f: … -43, -24, -17, **-44, -70** — '북'의 끝 자음이 시작하자마자 끊깁니다.
- 금도끼·의좋은·북풍 vox-f와 남자 목소리 전부: 30~60ms 에 걸쳐 서서히 작아집니다(자연스러운 끝).

`build.py` 의 `trim()` 은 마지막 큰 소리(-45dB 위) 뒤로 50ms 를 남기고 자릅니다.
그래서 이렇게 뚝 끊겼다는 것은 **엔진(VoxCPM2)이 만든 소리 자체가 거기서 끝났다**는 뜻입니다.
제목은 짧고 마침표가 없는 글이라 엔진이 일찍 멈춘 것으로 보입니다(추측 — 확인하지 않았습니다).

### 4. 재생 코드 (브라우저에서 `AudioBufferSourceNode.start` 를 기록, 브레멘 vox-f)
- **표지에서 '여자 목소리'를 누를 때**: `start(offset 0.35, duration 0.85)`. 구간 0.40~1.10 에 앞 0.05초·뒤 0.1초를
  더해 틀고, `ended`(저절로 끝남)까지 재생합니다.
- **읽어 주기 시작 → 제목 장면**: 같은 0.35 + 0.85 를 끝까지 재생합니다(`ended` 894ms). 그 뒤 장면 1 이 2.05초부터 시작합니다.
- 파일 안에서 제목 뒤 1초는 무음이라, 더 길게 틀어도 들릴 소리가 없습니다. → **코드는 고칠 것이 없습니다.**

## 고치는 순서 (VoiceStudio·VoxCPM2 가 있는 컴퓨터에서)

설치·켜는 법은 `picturebook/CLAUDE.md` 의 '맥에서 음성 만들기'를 따릅니다.
이 진단을 한 학교 윈도우 PC 에는 VoxCPM2 모델 가중치가 아직 없습니다(엔진 코드만 있음).

1. VoiceStudio 를 켭니다.
2. 책마다 여자 목소리 제목(문장 `#0`)만 다시 만들어 끼웁니다. 다른 문장과 남자 목소리는 그대로 둡니다.
   `retake.py` 는 한 번에 책 하나만 받습니다.
   ```
   python scripts/voice/retake.py bremen-musicians "vox-f:0=브레멘,음악대"
   python scripts/voice/retake.py tortoise-hare "vox-f:0=토끼,거북"
   python scripts/voice/retake.py goblin-club "vox-f:0=도깨비,방망이"
   ```
3. **주의 — `retake.py` 는 받아쓰기만 보고 고릅니다.**
   - 지금 들어 있는 소리가 받아쓰기로 '완벽'하면 새로 만들지 않습니다.
     **도깨비 방망이는 지금 소리도 받아쓰기로는 완벽**해서, 위 명령만으로는 바뀌지 않을 가능성이 큽니다.
   - 새로 만든 소리도 받아쓰기가 맞으면 바로 그것을 씁니다. 그런데 끝이 살짝 잘린 소리도 받아쓰기는 맞게 나올 수 있습니다.
   - 그래서 다시 만든 제목은 **사람이 직접 끝까지 들어 봐야 합니다.**
   - 도깨비처럼 바뀌지 않으면, `retake.py` 에 '지금 것이 완벽해도 새로 만들기' 선택지를 더하거나,
     후보를 wav 로 남겨 들어 보고 고르는 방법이 필요합니다(아직 만들지 않았습니다).
   - 제목 끝에 마침표를 붙여 읽히는 방법(`spoken()`)도 시험해 볼 만합니다. 효과는 확인하지 않았습니다.
4. 확인합니다.
   - `python scripts/voice/verify.py small bremen-musicians tortoise-hare goblin-club`
   - 표지에서 '여자 목소리'를 눌러 제목을 끝까지 들어 봅니다. 읽어 주기의 제목 장면도 들어 봅니다.
   - 남자 목소리와 나머지 세 권은 파일이 바뀌지 않았는지 `git diff --stat` 으로 봅니다
     (`audio/vox-f/` 의 세 파일과 `data/voice.json` 만 바뀌어야 합니다).
   - `npm test`(picturebook 폴더) — 음성 파일 이름의 글 해시는 그대로라 통과해야 합니다.
5. 이 브랜치에 커밋해 PR 을 갱신합니다. **확인을 끝낸 뒤에 머지합니다**(머지하면 그대로 발행됩니다).
