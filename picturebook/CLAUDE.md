  - 후보는 **실제 MP3 에 끼워 넣은 뒤** 받아 적어 고릅니다. 낱개 소리로는 맞게 들리던 것이 MP3 안에서는 틀리게
    들린 일이 있었습니다(2026-11-04 '산골'·'도끼').
  - 열몇 번 만들어도 늘 틀리면 `build.py` 의 `SAY`(읽을 때만 바꾸는 표기)에 넣습니다. 예: F5 '산골' → [상골] 이라 '산 골'로 넘김.
  - `build.py --force` 로 그 책을 다시 만들면 retake 로 고른 문장도 새로 뽑히니, 다시 확인해야 합니다.
  PowerShell 에서는 한글 출력이 깨지지 않게 먼저 `$env:PYTHONUTF8 = "1"` 을 둡니다.
- 받아쓰기(Whisper small) 결과를 그대로 믿지 않습니다(2026-11-04 '금도끼 은도끼'로 확인).

  (예: '퐁당' → 늘 '폭당')만 사람이 들어 볼 후보로 올립니다.
  - **'도끼' → '돋기'** 는 특히 믿지 않습니다. 손대지 않은 문장(M2 4장면)도 MP3 를 다시 굽기만 했는데
    '도끼'에서 '돋기'로 바뀌어 적혔습니다(2026-11-04). 사람이 들어 판단합니다.
