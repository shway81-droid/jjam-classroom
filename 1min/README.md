# ⏱ 짬짬이 1분 수업

**내일 나가는 그 차시, 1분 영상으로 열어 주세요.** — 교과서 차시를 1분 세로 영상으로 압축한 선생님 전용 모음.

[짬짬이 영상](https://shway81-droid.github.io/jjam-video/)이 "남은 시간에 뭐 틀지"를 해결한다면, 이 사이트는 **"지금 나가는 차시"**를 해결합니다. 그래서 필터를 늘어놓지 않고 **교과서 진도 순서**로 단원 → 차시를 그립니다. 선생님이 찾는 것은 차시 하나이고, 그건 필터보다 목차가 빠릅니다.

빌드 단계 없는 순수 정적 사이트입니다. 설치·로그인 없이 브라우저에서 바로 동작합니다.

## ✨ 기능

- **📖 교과서 진도 순서** — 단원 아래 차시 카드를 1번부터. 카드에 차시 번호와 길이가 찍혀 있습니다
- **🔍 검색** — 차시명·주제·핵심 낱말·단원 제목으로 찾기 ("고인돌", "3단원", "7차시" 모두 됩니다)
- **📱 세로 그대로 재생** — 9:16 숏폼을 잘라내거나 레터박스 없이 가운데에 띄웁니다. 옆에 차시명·요약·핵심 낱말이 붙습니다
- **📺 전자칠판 최적화** — 1280px 이상에서 글씨·카드 자동 확대, 전체화면 버튼
- **📴 오프라인 동작** — PWA + 서비스 워커. 목록·검색은 인터넷 없이도 동작합니다.
  *영상 재생은 유튜브를 부르므로 인터넷이 필요합니다.*

## 🎬 영상은 어떻게 만드나

교과서 차시 PDF를 **NotebookLM 숏폼 개요(짧은 버전, 9:16)** 에 넣어 1분 영상을 만들고,
사람이 교과서와 대조한 뒤 유튜브([`짬짬이 1분수업` @jjam1min](https://www.youtube.com/@jjam1min))에 Shorts 로 올립니다.
이 저장소에는 **영상 파일이 없습니다** — 유튜브가 호스팅이고 여기는 영상 ID만 듭니다.

생성 절차와 실측 기록은 이 저장소 밖(로컬 작업 폴더)에 있습니다.
화면과 내레이션은 AI 생성물이라 유튜브에도 AI 라벨을 붙였습니다.

## 🗂 구조

```
index.html               런처 (헤더·교과서 칩·검색·단원 섹션·세로 재생 모달)
style.css                클린 클래스룸 테마 + 소프트 3D 아이콘 (포인트색 번트오렌지)
app.js                   교과서 칩·검색·단원 묶음·모달 재생
shared/jjam-switcher.js  헤더의 자매 사이트 바로가기 (짬짬이 공통, 상류는 game/)
data/lessons.json        차시 데이터 (단일 소스)  ← 여기만 고치면 됨
data/lessons.index.json  ↳ 런처용 파생 파일 (자동 생성, 직접 수정 금지)
assets/fonts/            자가 호스팅 웹폰트 (Pretendard 서브셋, OFL 1.1)
sw.js · manifest.json    오프라인 지원(PWA)
favicon.svg
```

## ➕ 차시 추가·수정 방법

`data/lessons.json` 배열에 항목을 추가한 뒤 `node scripts/gen-data.mjs` 한 줄이면 끝입니다.

```json
{
  "id": "sa5-2-1-04",                  // 고유 식별자 (과목약칭-학년학기-단원-차시)
  "subject": "사회",
  "grade": 5,
  "semester": 2,
  "unit": 1,
  "unitTitle": "유적과 유물로 살펴본 옛 사람들의 생활",
  "lesson": 4,
  "lessonTitle": "청동기 시대에 사람들의 생활은 어떻게 달라졌을까요",
  "topic": "청동기 시대",              // 카드에 크게 보이는 짧은 이름
  "youtubeId": "Lp0WCji5NjA",          // 유튜브 URL 의 11자리
  "seconds": 68,                        // 영상 길이(초)
  "summary": "한두 문장 요약",
  "keywords": ["청동기", "고인돌"]      // 검색 대상 + 모달의 '핵심 낱말'
}
```

- **youtubeId**: `https://youtube.com/shorts/Lp0WCji5NjA` → `Lp0WCji5NjA`. 썸네일·재생이 자동 연결됩니다
- **unitTitle 은 같은 단원에서 글자 하나까지 같아야 합니다.** 엇갈리면 화면에 단원이 두 번 나오고, 검증이 실패시킵니다
- **topic 은 카드에 보이는 이름**입니다. `lessonTitle`(교과서 그대로)은 그 아래 작게 붙습니다

### 데이터 검증

차시를 추가·수정한 뒤 아래를 실행하면 됩니다. (PR·푸시 시 CI 가 동일하게 돌립니다)

```bash
node scripts/validate-data.mjs       # 필수 필드·중복·단원 제목 일관성
node scripts/gen-data.mjs            # 파생 파일 재생성
node scripts/check-font-coverage.mjs # 자가 호스팅 폰트에 없는 글자가 생겼는지
node scripts/check-sources.mjs       # 내 채널의 살아 있는 영상인지 (유튜브 조회)
```

## 🛡 무엇을 검증하고 무엇을 안 하나

짬짬이 영상은 **남의 영상**을 큐레이션하므로 승인 채널 목록·업로더 대조·썸네일 검토판까지 세 겹으로 막습니다. 이 사이트의 영상은 전부 **내가 교과서로 만들어 내 채널에 올린 것**이라 그 관문이 필요 없습니다. 그래서 두 가지만 봅니다.

1. **살아 있는가** — 삭제·비공개로 바뀌면 교실 화면이 검게 뜹니다. 주 1회 전수 점검합니다
2. **내 채널 영상인가** — 데이터에 남의 영상 ID 를 잘못 적는 것을 막습니다

유튜브 oEmbed 공개 엔드포인트만 쓰므로 API 키가 필요 없습니다.

### 대신 사람이 봐야 하는 것

**NotebookLM 은 내용을 바꿉니다.** 교과서에 없는 말을 만들고, 교과서에 없는 그림을 그립니다(한반도 지도를 육각형으로 그린 적이 있습니다). 그래서 영상마다 **사람이 프레임을 넘겨 보며 교과서와 대조한 뒤** 데이터에 넣습니다. 이건 자동화가 대신해 주지 않습니다.

## 사이트 아이콘

브라우저 탭·헤더 로고·앱 아이콘이 모두 **`favicon.svg` 한 파일**에서 나옵니다.

짬짬이 사이트는 **같은 틀 + 다른 알맹이**입니다 — 둥근 사각형 타일과 우상단 배지(흰 원 + 네이비 시계)는 같고, 바탕색과 가운데 심볼만 다릅니다.
게임 앰버 `#FFB703` · 퀴즈 그린 `#12A57C` · 영상 스카이 `#4FA8E8` · 이야기 퍼플 `#6145B5` · 낱말 로즈 `#E4576E` · **1분 수업 번트오렌지 `#E8590C`**.

홈 화면용 PNG는 `assets/icons/`에 있습니다. `og-image.png`·`og-image.svg`는 저장소 루트의 `scripts/gen-og.mjs`가 `favicon.svg`에서 만듭니다.

## 자매 사이트 바로가기

헤더 오른쪽 끝에 다른 짬짬이로 가는 버튼이 있습니다. 내용·스타일·아이콘이 모두 **`shared/jjam-switcher.js` 한 파일** 안에 있고, **`game/` 이 상류**입니다. 고칠 때는 거기서 먼저 고친 뒤 저장소 루트에서 아래를 실행하고 커밋합니다.

```bash
node scripts/sync-shared.mjs           # game/ 내용으로 공통 파일 맞추기
node scripts/sync-shared.mjs --check   # 어긋난 게 있는지만 확인 (CI 게이트와 같은 명령)
```

## ▶️ 로컬 실행

`fetch`로 JSON을 읽으므로 파일을 직접 여는 대신 로컬 서버로 엽니다.

```bash
python -m http.server 8000
# http://localhost:8000
```

## 🚀 배포

소스는 이 저장소(`jjam-classroom/1min/`)이고, 발행은 **`jjam-1min`** 저장소가 맡습니다.
GitHub Pages 주소가 저장소 이름에서 나오기 때문입니다 (`github.io/jjam-1min/`).

`main`에 머지되면 루트의 `발행 신호 보내기` 워크플로가 `jjam-1min`에 신호를 보내고 몇 분 안에 반영됩니다. 신호가 막히더라도 그쪽 저장소의 하루 한 번 크론이 안전망입니다.
