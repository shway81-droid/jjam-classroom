# 🎬 짬짬이 영상

**애매하게 남은 수업 시간, 뭐 틀지?** — 시간·주제·학년으로 1초 만에 찾는 선생님 전용 영상 아카이브.

[짬짬이 게임](https://shway81-droid.github.io/jjam/)의 클린 클래스룸 디자인과
[자투리타임](https://jaturi.me/)의 영상 큐레이션 콘셉트를 합친 **순수 정적 사이트**입니다.
설치·로그인 없이 브라우저에서 바로 동작하고, 서버가 필요 없습니다.

## ✨ 기능

- **⏱ 시간·👥 학년·🏷 주제 필터** — 남은 시간 안에 소화 가능한 영상만 1초에 추림
- **🔍 검색** — 제목·소개·주제 키워드로 바로 찾기 (필터·저장함·계기교육과 겹쳐 적용)
- **📅 계기교육 달력** — 기념일별 전용 영상 안내. 음력 명절(설날·추석·부처님오신날)은
  `app.js`의 `LUNAR_MD` 표(한국천문연구원 음양력 데이터, ~2036년)로 매년 자동 반영
- **🎲 룰렛으로 골라줘** — 현재 필터 안에서 랜덤 추천 후 바로 재생
- **🍿 오늘의 추천** — 첫 화면 추천 카드 + "추천 새로 받기"
- **⭐ 저장함** — 마음에 든 영상 담아두기 (브라우저 `localStorage`, 로그인 없음)
- **🧩 이렇게 써보세요** — 영상마다 수업 활용 아이디어 3가지
- **📺 전자칠판 최적화** — 1280px 이상 대화면에서 글씨·카드 자동 확대, 전체화면 버튼
- **📴 오프라인 동작** — PWA + 서비스 워커. 한 번 열어 두면 인터넷 없이도 목록·필터·검색·저장함이
  동작합니다(학교 크롬북·태블릿). *영상 재생 자체는 유튜브를 부르므로 인터넷이 필요합니다.*

## 🗂 구조

```
index.html               런처 (히어로·필터·그리드·모달) + 소프트 3D 아이콘 스프라이트
style.css                클린 클래스룸 테마 + 소프트 3D·다색 아이콘 (네이비·앰버 2026 트렌드)
app.js                   필터·룰렛·저장함(localStorage)·모달 재생
shared/jjam-switcher.js  헤더의 자매 사이트 바로가기 (네 저장소 공통, 상류는 jjam)
data/videos.json         영상 큐레이션 데이터 (단일 소스)  ← 여기만 수정하면 됨
data/videos.index.json   ↳ 목록·필터·검색용 파생 파일 (자동 생성, 직접 수정 금지)
data/videos.detail.json  ↳ 모달 전용 파생 파일 (자동 생성, 직접 수정 금지)
assets/fonts/            자가 호스팅 웹폰트 (Pretendard 서브셋, OFL 1.1)
sw.js · manifest.json    오프라인 지원(PWA)
favicon.svg
```

### 첫 화면이 받는 데이터

`videos.json`은 사람이 읽기 좋게 들여쓴 파일이라 절반 이상이 공백이고, 카드 그리드에서
쓰지도 않는 `ideas`(활용 아이디어 3가지)까지 들어 있습니다. 그래서 런처는 원본 대신
`scripts/gen-data.mjs`가 만든 파생 파일을 받습니다.

| | 크기 | 언제 받나 |
|---|---|---|
| `videos.json` (원본) | 284 KB | 받지 않음 — 사람이 고치는 파일 |
| `videos.index.json` | **88 KB** | 첫 화면 (목록·필터·검색) |
| `videos.detail.json` | 44 KB | 첫 화면을 그린 뒤 배경에서 |

`description`은 검색 대상이라 목록에 남아 있고, `ideas`만 상세로 뺐습니다.
`channel`은 사람이 검토할 때만 쓰는 기록이라 파생 파일 어느 쪽에도 넣지 않습니다.

## ➕ 영상 추가·수정 방법

`data/videos.json` 배열에 항목을 추가한 뒤 `node scripts/gen-data.mjs` 한 줄이면 끝입니다.

```json
{
  "id": "unique-slug",                        // 고유 식별자 (영문·숫자·하이픈)
  "title": "지식채널e - 나는 정말 의지력이 부족한 걸까",
  "youtubeId": "Q4cC7WrBk9s",                 // 유튜브 URL의 v= 뒤 11자리
  "channel": "EBS 지식채널e",                   // 영상을 올린 유튜브 채널 (승인 목록에 있어야 함)
  "topic": "인성",                             // 주제 (아래 목록 참고)
  "grade": ["중학년", "고학년"],                // 저학년 / 중학년 / 고학년 중 해당되는 것
  "minutes": 5,                               // 영상 길이(분)
  "description": "영상 한 줄 소개",
  "ideas": ["활용법 1", "활용법 2", "활용법 3"]   // 수업 활용 아이디어 3가지
}
```

- **youtubeId**: `https://www.youtube.com/watch?v=Q4cC7WrBk9s` → `Q4cC7WrBk9s`
  (`https://youtu.be/Q4cC7WrBk9s`의 뒷부분과 동일). 썸네일·재생이 자동 연결됩니다.
- **topic 권장 목록**: 인성, 진로, 건강·보건, 생명존중, 세계시민, 가족, 역사,
  다문화, 학교폭력예방, 힐링·재미, 경제, 인권, 독도, 민주시민, 예술·문화, 스포츠, AI교육,
  미디어리터러시, 장애인식개선, 안전, 과학·탐구, 학급자치, 통일, 환경생태
  *(목록에 없는 주제를 써도 필터에 자동 추가됩니다.)*
- **channel**: 영상을 올린 유튜브 채널명을 **그대로** 적습니다(영상 페이지의 채널 이름).
  `data/channels.json` 승인 목록에 없는 채널이면 검증이 실패합니다 — 아래 "유해 영상 거르기" 참고.
- `youtubeId`가 `"SAMPLE"`이면 예시 카드로 표시됩니다. 실제 ID로 바꾸세요.

### 데이터 검증

영상을 추가·수정한 뒤 아래를 실행하면 됩니다. (PR·푸시 시 CI가 동일하게 돌립니다)

```bash
node scripts/validate-data.mjs       # 데이터가 올바른지 (+ 승인 채널인지)
node scripts/gen-data.mjs            # 파생 파일 재생성 (index·detail)
node scripts/check-font-coverage.mjs # 자가 호스팅 폰트에 없는 글자가 생겼는지
node scripts/check-sources.mjs       # 출처가 진짜인지 (유튜브 조회 — 인터넷 필요)
```

필수 필드·`id`/`youtubeId` 중복·학년 이름·`ideas` 3개 규칙을 확인하고, **런처가 실제로 찾을 수
있는 데이터인지**까지 봅니다 — 시간 필터에 없는 `minutes`, 달력에 없는 `occasions` 처럼
데이터에는 있어도 화면에서 도달할 수 없는 항목을 걸러냅니다. 판정 기준은 `app.js`의 상수에서
읽어 오므로, 상수를 고치고 데이터를 안 고치면 검증이 실패해 알려 줍니다.

## 🛡 유해 영상 거르기

초등 교실에서 바로 트는 자료라, 학생에게 부적절한 영상이 한 편이라도 섞이면 안 됩니다.
실제로 두 번 섞여 든 적이 있고(`3분휴지`의 '스승의 날 특집', `현대불교`의 '불교 문화
이야기'), **두 번 다 제목·소개는 멀쩡했고 업로드 채널만 달랐습니다.** 제목과 소개는
사람이 고쳐 적는 값이라 믿을 수 없고, 채널은 유튜브가 알려 주므로 속일 수 없습니다.

그래서 채널을 축으로 세 겹으로 막습니다.

### 1. 승인 채널 목록 — 새 채널은 사람이 승인해야 들어온다

영상마다 `channel`을 적고, 그 채널이 `data/channels.json`에 없으면
`validate-data.mjs`가 **실패**시킵니다. 인터넷 없이 도는 빠른 관문입니다.

```
✗ videos[423] (yt-xxxx): 승인되지 않은 채널 '3분휴지' — 학생에게 보여도 되는
  채널인지 확인한 뒤 data/channels.json 에 승인 사유와 함께 추가해 주세요.
```

새 채널의 영상을 넣으려면 **그 채널을 직접 열어 보고** 목록에 한 줄을 추가합니다.
값은 왜 써도 되는지 적는 자리입니다 — 빈 값이면 검증이 실패합니다.

```json
{
  "교육부": "2026-09-08 전수 점검 통과",
  "○○교육청": "시도교육청 공식 채널 · 2026-09-08 확인"
}
```

이 한 줄을 적는 순간이 곧 검토 시점이고, PR diff 에 남아 리뷰어도 보게 됩니다.
쓰지 않게 된 채널은 경고로 알려 주니 영상을 뺄 때 함께 지워 주세요.

### 2. 출처 검증 — 적어 둔 채널이 진짜인지 대조한다

승인된 채널명을 적어 두고 엉뚱한 영상을 넣으면 1번은 통과합니다.
`check-sources.mjs`가 유튜브에 직접 물어 **실제 업로더**와 대조합니다.

```
✗ yt-xxxx '스승의 날 특집': 적어 둔 채널과 실제 업로더가 다릅니다.
      적힌 채널: 교육부
      실제 업로더: 3분휴지
      실제 제목: 2026 스승의 날 특집, 선생님 감사합니다
```

영상이 삭제·비공개로 바뀐 것도 함께 잡습니다(교실에서 검은 화면이 뜨는 것을 막습니다).
CI 는 PR 에서 **바뀐 영상만** 보고(빠르고, 유튜브가 잠시 응답을 안 해도 관계없는 PR 이
빨간불이 되지 않습니다), **주 1회 전수 점검**으로 나중에 죽은 영상을 잡습니다.
유튜브 oEmbed 공개 엔드포인트만 쓰므로 API 키가 필요 없습니다.

### 3. 썸네일 검토판 — 기계가 못 보는 것

"이 그림을 교실 화면에 띄워도 되는가"는 자동 판정할 수 없습니다. 실제로 '불교 문화
이야기'는 썸네일에 총구를 겨눈 장면이 있었습니다. 사람이 훑어볼 수 있게 한 화면으로
모아 줍니다.

```bash
node scripts/thumb-sheet.mjs --since origin/main   # 새로 추가한 영상만
node scripts/thumb-sheet.mjs                       # 전체
```

`thumb-sheet.html`이 만들어집니다. 브라우저로 열어 넘겨보고, 이상하면 그 카드를 눌러
유튜브에서 바로 확인하세요. (검토용 임시 파일이라 `.gitignore`에 있습니다.)

### 한계

채널·출처·썸네일까지는 걸러지지만 **영상 본편의 중간 내용은 아무도 대신 봐 주지
않습니다.** 새 영상은 한 번 재생해 보고 넣어 주세요.

## 사이트 아이콘

브라우저 탭·헤더 로고·앱 아이콘이 모두 **`favicon.svg` 한 파일**에서 나옵니다.
헤더 로고도 이 파일을 그대로 쓰므로 탭과 화면이 어긋날 일이 없습니다.

짬짬이 4개 사이트는 **같은 틀 + 다른 알맹이**입니다 — 둥근 사각형 타일과 우상단
배지(흰 원 + 네이비 시계, “자투리 시간”)는 넷이 같고, 바탕색과 가운데 심볼만 다릅니다.
게임 앰버 `#FFB703` · 퀴즈 그린 `#12A57C` · 영상 스카이 `#4FA8E8` · 이야기 퍼플 `#6145B5`.

홈 화면용 PNG는 `assets/icons/`에 있습니다. 안드로이드·iOS 홈 화면은 SVG를 쓰지 않아
PNG가 따로 필요합니다(없으면 “홈 화면에 추가”에서 아이콘이 비어 보입니다).

PNG는 `favicon.svg`에서 생성한 파생물입니다. 아이콘을 고쳤다면 짬짬이 게임 저장소의
`scripts/gen-icons.mjs`로 다시 만드세요 — 안드로이드 안전 영역·iOS 여백 비율이 그 안에 들어 있습니다.

## 자매 사이트 바로가기

헤더 오른쪽 끝에 **짬짬이 게임·퀴즈·이야기로 바로 가는 버튼 세 개**가 있습니다.
선생님에게는 넷이 "자투리 시간에 쓰는 짬짬이" 하나인데, 지금까지는 한 곳에 들어오면
나머지 셋이 있다는 걸 알 방법이 없었습니다.

아이콘만 두는 안도 검토했지만, 처음 보는 사람은 그 그림이 "다른 사이트로 가는 것"인 줄
모릅니다(구글의 점 아홉 개처럼 이미 학습된 기호가 아닙니다). 그래서 **아이콘 아래에 이름**을
붙였습니다. 좁은 화면(720px 이하)에서는 이름을 감추고 아이콘만 남깁니다.

오프라인에서는 흐리게 표시되고 눌러도 이동하지 않습니다. 네 사이트는 캐시가 따로라
인터넷 없이 건너갈 수 없는데, 그냥 이동시키면 **지금 쓰던 화면까지 잃기** 때문입니다.

내용·스타일·아이콘이 모두 **`shared/jjam-switcher.js` 한 파일** 안에 있고, 넣는 쪽은 헤더에
host 한 줄뿐입니다. 이 파일은 다섯 폴더에서 글자 하나까지 같아야 하므로
**`game/` 이 상류**입니다 — 주소·이름·아이콘을 고칠 때는 거기서 먼저 고친 뒤
저장소 루트에서 아래를 실행하고 커밋합니다. (모든 PR 에서 CI 가 이탈을 막습니다.)

```bash
# 저장소 루트에서
node scripts/sync-shared.mjs           # game/ 내용으로 공통 파일 맞추기
node scripts/sync-shared.mjs --check   # 어긋난 게 있는지만 확인
```

## 🚀 배포 (GitHub Pages)

정적 파일이므로 저장소를 Pages로 연결하면 그대로 배포됩니다.
(루트에 `index.html`이 있으므로 `main` 브랜치 / root 설정)
