# 오락실 말놀이 3종 — 설계

2026-09-28. 예능 프로그램(지구오락실)의 놀이 가운데 "보기 없이 입으로 외치는" 원칙에
맞는 것을 골라 짬짬이 낱말에 옮긴다.

## 고른 것과 뺀 것

| 놀이 | 결정 | 이유 |
|---|---|---|
| 4글자 이어말하기 | 넣음 (문항형) | 문제 → 힌트 → 정답 흐름 그대로 |
| 줄줄이 말해요 | 넣음 (도구형) | 끝말잇기 판을 그대로 쓰고 제시어만 다르다 |
| 인물퀴즈 | 넣음 (문항형, 사진) | 사진은 자유 라이선스만 |
| 음악·OST 퀴즈, 세 글자 노래방 | 뺌 | 음원 저작권, 외부 음원 금지 원칙 |
| 명대사, 과자·빵 이름 | 뺌 | 저작권, 상표 광고 |

화면에는 방송 이름을 쓰지 않는다. 묶음 이름은 "오락실 말놀이".

## 홈

진행 도우미 아래 세 번째 묶음. TYPES 에 `arcade: true` 를 달면 그 묶음에 선다.
`kind`(quiz/tool)는 동작을, `arcade` 는 자리만 정한다.

## 4글자 이어말하기 (`fourword`)

- `prompt` = 앞 두 글자 + `______`, `answer` = 뒤 두 글자, `hint` = 답의 초성(기계적으로)
- 정답 단계에서 빈칸이 채워져 네 글자가 한 줄로 보인다(속담의 `fillBlank` 재사용)
- 사자성어와 일상 네 글자 말(옹기종기·싱글벙글…)을 섞는다. 150문항(60/60/30)
- 기존 사자성어 유형(뜻 → 사자성어)과 문항이 겹쳐도 된다 — 묻는 방식이 다르다

## 줄줄이 말해요 (`relay`)

- 데이터는 한글 한 글자(`word: "가"`). 60개(25/20/15) — 낱말이 많은 글자가 쉬움
- 끝말잇기와 같은 판: 모둠 수·제한 시간·성공/탈락·지나간 차례. `ROUND_TYPES`
- 끝말잇기와 달리 난이도를 고를 수 있다

## 인물퀴즈 (`person`)

- 분야 7종 `PERSON_TOPICS` — 낱말 주제(`TOPICS`)와 섞지 않는다
- 문제: 사진 + "누구일까요?" / 힌트: `초성 · 설명` / 정답: 이름 + 사진 출처
- 사진: 위키데이터 대표 이미지(P18) → 위키미디어 공용에서 라이선스 확인 → 480px WebP.
  CC0·퍼블릭 도메인·CC BY·CC BY-SA·공공누리 1유형만. 자유 사진이 없는 인물은 빠진다
  (조세호: 사진 없음, 송강호: 인도 정부 라이선스라 제외)
- 사진을 눈으로 확인해 바꾸거나 뺐다: 안유진(미성년 때 사진 → 2024년 사진),
  오상욱(마스크 → 다른 사진), 라이트 형제(한 명만 찍힘 → 뺌)
- 정치인·논란 인물은 넣지 않는다. 설명에 외모 이야기를 넣지 않는다
- 사진은 서비스워커가 미리 받지 않는다. 못 불러오면 힌트를 바로 연다
- 단계가 넘어갈수록 사진이 줄어든다(38vh → 30vh → 22vh) — 1280×720 에서 문제·힌트
  단계가 한 화면에 든다

## 검증

`validate-data.mjs` 가 새로 강제하는 것 — 유형별 분포, 4글자 형식과 초성 힌트,
줄줄이 제시어는 한 글자, 인물 분야, 인물 힌트의 초성, 사진 필드·라이선스·출처 주소·
파일 존재·중복, `assets/people/` 에서 아무도 안 쓰는 사진.

## 공통 폰트

인물 이름·설명에 새 글자 27자가 생겨 `game/` 의 Pretendard 서브셋을 다시 만들고
`sync-shared` 로 여섯 사이트에 퍼뜨렸다(1839 → 1866자). 원본은 Pretendard v1.3.9.
