## 4. 카드 하나 더하기

1. `kinder/data/cards.json`의 `items`에 한 줄을 더합니다.
   ```json
   { "id": "penguin", "word": "펭귄", "topic": "동물", "hint": "두 팔을 몸에 붙이고 뒤뚱뒤뚱 걸어요" }
   ```
   - `id`: 영문 소문자만(그림 파일 이름이 됩니다)
   - `word`: 한글 1~5글자, 유치원 아이가 날마다 보는 말
   - `hint`: 40자 안, **정답 낱말을 쓰지 않습니다**(읽어 주면 답이 새어 나감)
2. `kinder/assets/cards/<id>.svg`를 그립니다 — 그림 규칙은 `kinder/CLAUDE.md`의 "그림 규칙"을 따릅니다.
   - `viewBox="0 0 240 240"`, 테두리 `#3B2F2F` 굵기 7, 정해 둔 색만, 그림 안에 글자 금지
   - 그린 뒤 **반드시 화면에 띄워 눈으로 확인**합니다(기존 그림과 나란히).
3. `kinder/sw.js`의 `ASSETS`에 `'./assets/cards/<id>.svg'`를 더합니다.
4. `cd kinder && npm test` — 빠진 것이 있으면 검사가 알려 줍니다.

## 5. 꼭 기억할 함정

- **폰트에 없는 글자**: 화면 글자는 Pretendard 서브셋에 있는 것만 씁니다. 예전에 '뭘'·'뻥'이
  없어서 '무엇일까요'·'힘껏'으로 바꿨습니다. 서브셋을 새로 만들면 일곱 사이트가 모두 다시
  발행되므로 **낱말 쪽을 바꾸는 것이 먼저**입니다. `npm test`가 빠진 글자를 알려 줍니다.
- **공유 카드(og-image)**: 루트에서 `node scripts/gen-og.mjs`를 돌리면 **다른 사이트의
  og-image.png도 다시 구워집니다.** `kinder/og-image.png`만 남기고 나머지는
  `git checkout -- <사이트>/og-image.png`로 되돌립니다(안 그러면 그 사이트들이 다시 발행됨).
  playwright가 game/에 없으면 `NODE_PATH=$(npm root -g) node scripts/gen-og.mjs`.
- **공통 파일 5종**(`shared/jjam-switcher.js`, `scripts/check-font-coverage.mjs`, `assets/fonts/*`)은
  `kinder/`에서 손으로 고치지 않습니다. `game/`에서 고친 뒤 루트에서 `node scripts/sync-shared.mjs`.
- **`home/`과 일곱 사이트 폴더는 건드리는 순간 배포**입니다. 유치원 작업은 `kinder/` 안에서만 합니다.
