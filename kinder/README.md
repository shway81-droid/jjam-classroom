# 짬짬이 유치원

글자를 아직 못 읽어도 **그림만 보면 아는** 유치원 놀이입니다. 전자칠판에 그림 카드를 크게 띄웁니다.

- **몸으로 말해요** — 한 친구가 화면을 등지고 서면 나머지 친구들이 그림을 보고 몸으로 알려 줍니다.
  흉내를 어떻게 낼지 모르는 아이를 위해 카드마다 **몸짓 힌트**가 있습니다.
- **무엇일까요?** — 그림을 보고 다 같이 이름을 외칩니다. [정답 보기]를 누르면 글자가 나타나고 소리로 읽어 줍니다.

카드 41장 — 동물 13 · 먹을거리 8 · 탈것 7 · 물건 8 · 자연 5. 그림은 모두 같은 그림체로 새로 그렸습니다(외부 그림 0장).

조작: `Space`·`Enter`·`→` 다음 / `Esc` 처음으로. 설치·로그인 없음, 인터넷이 끊겨도 동작합니다.

```bash
python3 -m http.server 8380   # 이 폴더에서
npm test                      # 검증
```
