# 짬짬이 이야기 MVP 제품 요구사항 정의서(PRD)

- **버전:** 1.0
- **형태:** 정적 웹 MVP
- **배포:** GitHub Pages

## 핵심 정의

| 항목 | 내용 |
|---|---|
| 서비스명 | 짬짬이 이야기 |
| 핵심 사용자 | 전자칠판을 사용하는 초등학교 교사 |
| 핵심 상황 | 수업 전후 3~7분의 자투리 시간 |
| 핵심 가치 | 짧은 이야기 하나로 학생이 생각하고 말하게 한다. |
| 핵심 흐름 | 유형 선택 → 조건 선택 → 이야기 읽기 → 생각 → 대화 → 발표 → 마무리 |
| MVP 범위 | 5개 유형, 20개 이야기, 3·5·7분 모드, 단계별 진행 및 타이머 |

## 1. 제품 개요

### 1.1 한 문장 정의
교사가 이야기 유형과 활동 시간을 선택하면, 학생들이 짧은 이야기를 듣고 상상·추리·말하기·이어쓰기를 할 수 있도록 단계별 진행 화면을 제공하는 전자칠판용 웹서비스입니다.

### 1.2 해결하려는 문제
- 수업이 3~7분 일찍 끝났을 때 교사가 즉시 활용할 수 있는 활동을 찾기 어렵습니다.
- 짧은 말하기 활동을 하려 해도 이야기와 질문, 진행 순서를 매번 준비해야 합니다.
- 기존 퀴즈 활동은 정답 맞히기에 치우쳐 상상, 근거 말하기, 관점 바꾸기 활동이 부족합니다.
- 교사용 진행 멘트와 타이머가 한 흐름으로 제공되지 않습니다.

### 1.3 목표
- 접속 후 10초 안에 활동 시작
- 1분 안에 읽을 수 있는 짧은 이야기
- 화면 안내만으로 진행 가능
- 정답보다 근거와 다양한 관점 강조
- 3분·5분·7분 안에 실제 종료

### 1.4 비목표
- 국어 교과 전체 대체
- 학생 답변 저장·평가
- 실시간 AI 채점
- 회원가입·학급 계정·커뮤니티
- 긴 동화·독서 수업 플랫폼

## 2. 사용자와 환경

### 주요 사용자
- 1차: 초등학교 교사
- 2차: 초등학생
- 보조: 연수 강사 및 수업 연구자

### 사용 환경
- 전자칠판, 대형 TV, 프로젝터
- Chrome·Edge 등 최신 브라우저
- 학생 개인 기기나 계정 없이 전체 참여
- 정적 파일로 실행 가능

## 3. 콘텐츠 체계

### MVP 이야기 유형
1. 다음 이야기 — 다음 장면 상상
2. 왜 그랬을까 — 행동 이유 추리
3. 마음 읽기 — 감정과 근거 추론
4. 선택 이야기 — 선택과 이유 말하기
5. 한 문장 이어쓰기 — 이야기 확장

각 유형 4편, 총 20편으로 시작합니다.

### 작성 기준
- 저학년 2~3문장, 중학년 3~5문장, 고학년 5~7문장
- 100~250자 안팎
- 정답을 직접 제시하지 않음
- 질문은 한 화면에 하나씩 공개
- 예시 생각은 정답이 아닌 가능한 답으로 표현

### 안전 기준
가족의 죽음, 중증 질병, 가정폭력, 아동학대, 자해, 심각한 학교폭력, 외모·성적·가정형편 조롱, 높은 공포 수위, 정치·종교 강요 소재는 MVP에서 제외합니다.

## 4. 핵심 흐름

```text
홈 → 이야기 유형 선택 → 학년·시간·활동 방식 선택 → 이야기 읽기 → 혼자 생각 → 짝/전체 대화 → 발표 → 추가 질문/예시 생각 → 마무리
```

### 시간별 진행
- **3분:** 이야기 40초 → 생각 30초 → 발표 1분 30초 → 마무리
- **5분:** 이야기 40초 → 생각 30초 → 짝 대화 1분 → 발표 2분 → 추가 질문
- **7분:** 이야기 1분 → 생각 30초 → 짝 대화 1분 30초 → 발표 2분 → 확장 활동 1분 30초

## 5. 화면
1. 홈
2. 조건 선택

4. 혼자 생각하기

  "id": "next-001",
  "title": "열면 안 되는 창문",
  "type": "next-story",
  "grades": ["middle", "upper"],

  "activityModes": ["individual", "pair", "whole"],
  "story": ["..."],

  "followUpQuestions": ["다음에는 어떤 일이 일어날까요?"],

## 8. 추천·진행 로직
- 유형, 학년, 시간 조건을 만족하는 이야기만 후보로 사용
- 최근 사용 10편 우선 제외
- 후보가 없으면 최근 사용 제외 조건 초기화
- sensitivity=low만 노출
- 진행 상태: `SETUP → STORY → THINK → TALK → PRESENT → EXTEND → COMPLETE`

## 9. 비기능 요구사항
- 최초 화면 2초 이내 목표
- 키보드 접근과 명확한 포커스
- 전자칠판 본문 최소 32px 상당
- 개인정보 입력 없음
- 최신 Chrome·Edge 우선 지원
- JSON 추가만으로 콘텐츠 확장
- GitHub Pages 배포

## 10. 기술 구성
- HTML, CSS, Vanilla JavaScript
- stories.json
- LocalStorage
- GitHub Pages

## 12. 완료 기준
- 홈에서 10초 안에 실행
- 전체 20편 표시

## 14. 제품 원칙

> **짧은 이야기 하나로, 교사의 준비는 줄이고 학생의 생각과 말은 늘린다.**

모든 기능은 `10초 안에 시작`, `한 화면에 한 단계`, `정답보다 근거와 상상` 원칙을 따릅니다.
